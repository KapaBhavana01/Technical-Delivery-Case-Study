# Project Overview

## Project Purpose

This project demonstrates how a technical analytics and machine learning initiative can be planned, coordinated, developed, tested, and evaluated through a structured delivery lifecycle.

The technical implementation uses the Kedro Spaceflights project as the foundation. The project is being extended as a portfolio case study to demonstrate technical delivery, Agile planning, requirements management, quality validation, and technical decision support.

## Delivery Approach

The project began with exploratory analysis using Jupyter notebooks to assess the available data, understand data quality, identify relevant attributes, and explore the feasibility of the analytics use case.

Following initial analysis and requirements, the exploratory workflow was structured into reusable Kedro pipelines to support a more organized and repeatable implementation.

## Business Problem

The case study focuses on predicting shuttle ticket prices using historical data.

The objective is to develop and evaluate a machine learning solution while demonstrating the delivery activities surrounding the technical work.

## Delivery Objective

The project follows the lifecycle:

Requirements → Planning → Technical Design → Development → QA & Validation → Model Evaluation → Release Assessment → Retrospective

## My Role

The project is designed from a Technical PMO / Technical Delivery perspective.

Responsibilities demonstrated in this case study include:

- Translating the business problem into delivery requirements
- Structuring and tracking the technical backlog
- Defining acceptance criteria
- Tracking dependencies, risks, and delivery milestones
- Coordinating technical work across the delivery lifecycle
- Supporting QA and validation activities
- Facilitating technical discussions and model evaluation
- Documenting decisions and delivery status
- Supporting release readiness assessment
- Identifying opportunities for process improvement

## Technical Scope

The technical implementation includes:

- Python
- Kedro
- Pandas
- Scikit-learn
- Data preprocessing
- Machine learning model development
- Model evaluation
- Pipeline execution
- Testing and validation

## Project Origin

This project extends the official Kedro Spaceflights tutorial as the technical foundation for this portfolio case study.

The [original tutorial](https://docs.kedro.org/en/stable/tutorials/spaceflights_tutorial/) provides the foundation for the data science pipeline. Additional documentation, delivery artifacts, and project-management practices are being developed as part of this case study.
